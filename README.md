# 食品価格ウォッチ

食品の価格・セール情報を表示するウェブサイト。価格データは Yahoo!ショッピング 商品検索API からサーバー側で取得します（6時間キャッシュ、取得できない場合は同梱の prices.json スナップショットを表示）。

## 必要な環境変数

- `YAHOO_CLIENT_ID` — Yahoo!デベロッパーネットワークの Client ID。Altare の Deployments → Settings → Variables で設定します。リポジトリには絶対に含めないでください。

## 起動

```
python3 server.py
```

`PORT` 環境変数のポートで `0.0.0.0` にバインドします。依存パッケージはありません（Python 標準ライブラリのみ）。

## セキュリティ

- 個人情報は収集しません（アカウント機能なし）。
- APIキーはサーバー側の環境変数でのみ保持し、ブラウザ側のコードには含めません。
- セキュリティヘッダー（CSP など）を全レスポンスに付与します。
